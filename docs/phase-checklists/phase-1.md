## 已知限制与验收备注

- 示例文档、活动、图谱和清理建议均为演示数据。
- Workspace 仅预览本机选中文件的信息，页面刷新后不保存选择。
- AI Search 不执行语义检索，来源卡片不代表针对输入问题生成的真实回答。
- Knowledge Graph 尚未集成 React Flow，关系不来自 AI 推断。
- Cleanup 不修改文件或标签，差异仅说明建议的表现形式。
- 浏览器检查视口：1440×900、1280×720、768×1024、390×844，另检查 390×420 矮屏导航。
- 浏览器运行时异常与本地资源失败均为 0；本轮未做跨浏览器矩阵或真实 AI/数据库测试。
- 本机截图和交互报告位于 `artifacts/qa`，不提交到 Git。UI 机械检测发现的一处厚侧边已删除。
