# 搜索失败、拒答与降级恢复验收

日期：2026-10-26。范围：现有个人资料搜索、历史结果及来源预览。

## 公开原因与恢复操作

服务端在实际执行分支提供 `SearchResult.issues`；HTTP/SSE 失败提供 `reason`。界面只按公开枚举映射说明，不显示原始错误字符串、服务内部堆栈或凭据。

| 原因标识 | 判定依据 | 可用恢复操作 |
| --- | --- | --- |
| `PREPARATION_INCOMPLETE` | 当前授权范围的统一准备状态中，已保存数大于可搜索数 | 准备未完成资料、手动重试 |
| `NO_RELEVANT_CONTENT` | 本次没有召回达到现有门槛的相关证据；最接近片段继续保留 | 调整问题、查看可用片段、手动重试 |
| `MISSING_REQUESTED_FACTS` | 结构化资料判断列出具体缺失项，或多来源覆盖元数据标记对应缺失事实 | 查看原文、调整问题 |
| `VERIFICATION_FAILED` | 事实验证拒绝，或引用校验失败；修正后改为拒答不能抹去先前的验证失败 | 查看原文、手动重试、调整问题 |
| `ANSWER_SERVICE_UNAVAILABLE` | 未配置可用回答服务，或生成/验证调用未能完成 | 查看可用原文、稍后手动重试 |
| `SOURCES_CHANGED` | 引用发布前复核失败、历史片段与现状不符、选定资料或来源已不可访问 | 在相同范围重新搜索、查看保存片段 |
| `SEMANTIC_UNAVAILABLE` | 现有检索引擎明确回退至关键词检索 | 调整关键词、稍后手动重试 |
| `INSUFFICIENT_EVIDENCE` | 有证据但不足以回答，且没有可靠的具体缺失事实判断 | 通用说明、查看原文、调整问题、手动重试 |
| `SEARCH_UNAVAILABLE` | 未分类失败、连接中断、未知原因码 | 通用说明、手动重试、调整问题 |
| `HISTORY_UNVERIFIED` | 旧问答记录缺少验证信息 | 隐藏回答正文、保留片段、在原范围重新搜索 |

原因可并存，例如资料未准备完成且本次未召回。旧记录不会根据拒答文字或错误字符串补出“已验证”或“缺少事实”的结论；只有明确保存的验证成功状态可以显示回答。历史读取不改写数据库中的旧记录。

## 范围、保留与调用约束

- 复用现有按身份、工作区、文档集合过滤的索引状态汇总及准备逻辑；状态查询保持有界，不遍历整个资料库。
- 搜索、调整问题后的提交和手动重试持续携带当前工作区与文档集合；失效选择直接失败，不退回全部资料。
- 准备操作只处理当前范围内的未完成资料，跳过已完成和正在处理的资料。准备结束不自动搜索或生成回答。
- 沿用既有的单次有界事实/引用修正预算；恢复界面没有新增自动模型重试。每次手动恢复只发起一次搜索请求。
- 加载和取消保留上次结果；新的结构化失败保留上次通过验证的答案或成功查找到的片段，并标明属于上次结果。
- 保持原有事实验证、数值检查、引用范围与发布前来源复核门槛；不发送生成草稿事件。旧历史缺少验证信息时，服务端移除响应中的回答正文。
