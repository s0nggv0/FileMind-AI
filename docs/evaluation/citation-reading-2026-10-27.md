# 引用原文定位与返回流程验收

日期：2026-10-27。范围：搜索引用预览、提取全文、资料详情深链接与受保护原件访问。

## 行为与定位依据

- 保留引用按钮、相关资料/来源列表、打开资料、原文件、图谱、提取全文与分类标签入口。引用预览增加约前后各 400 字符的上下文，按需读取全文，不增加模型调用。
- 扩展既有受保护的 `GET /api/search?chunkId=...`：`view=context|full` 使用分块 ID、文档 ID、分块内容哈希、分块版本、保存字符范围及可用的文档哈希核对来源。一个 SQL 语句读取同一身份下的分块、正文与结构快照。
- 同时核对当前分块位置、原文切片与分块内容哈希。重复句子使用保存的偏移，不进行第一次文本匹配。字符偏移沿用提取流程的 JavaScript 字符串坐标，起点含、终点不含。
- 首次读取返回全文内容版本 `textVersion`；切换全文和资料深链接持续携带该版本，避免在两次读取间将旧位置应用到新正文。来源不匹配或不可访问返回公开的 `SOURCES_CHANGED`，不返回当前正文或套用旧范围。
- 旧引用缺少完整位置或版本字段时返回 `unavailable`、空定位范围和明确说明；仍保留可核对片段，不按重复文本猜测位置。
- 深链接只包含 ID、哈希、版本、偏移及原搜索记录 ID，不在 URL 中放入正文。资料读取仍由签名身份、显式所有者条件和数据库 RLS 保护。

## 格式支持

| 格式 | 提取全文定位 | 原件定位与限制 |
| --- | --- | --- |
| PDF | 保存的字符范围高亮；页码须同时匹配分块和提取结构的真实页记录 | 有可靠页码时使用受保护原件地址的 `#page=`；没有页记录时明确说明，不估算页码 |
| DOCX | 使用保存的字符范围高亮，并显示已保存段落/标题信息 | 原件仍可下载；不虚构 Word 分页，不控制本地 Word 编辑器光标 |
| TXT | 使用保存字符范围高亮，保留行位置说明 | 原件按既有方式打开；不假设浏览器原生文本查看器支持字符定位 |
| Markdown | 使用保存字符范围高亮，保留行和标题信息；按安全纯文本阅读 | 不渲染文档自带 HTML，不虚构分页 |
| 图片 | 引用文字继续区分 OCR 与 AI 解读，可核对保存的文字范围和上下文 | 保留原图入口；没有可靠的引用到图片区域映射时不绘制区域高亮，即使 OCR 结果包含独立的块坐标也不按重复文本猜测 |

提取全文中的高亮范围对应引用分块，未提供答案中单个词句到原件像素坐标的映射。PDF 原件中的精确文字框选、Word 原生编辑器定位和图片区域定位尚未支持；浏览器对 PDF 页码片段的处理由其原生查看器决定。

## 阅读、恢复与权限

- 搜索预览中可切换片段/全文，关闭、Esc 或“返回搜索结果”恢复原引用焦点。资料详情可返回保存的搜索记录，恢复引用焦点及记录中的工作区/文档范围。
- 正文自动定位只滚动内部阅读区域，标题与返回操作保持可见。保留手机布局、键盘滚动和手动重试。
- 当资料不在最近 1500 条列表中时，直接通过受保护文档 ID 接口加载；列表为空或来源失效时也不改用示例资料冒充详情。
- 原件不可用时继续阅读已保存提取正文。引用发起的原件地址携带预期文件版本；接口在返回原件前校验该版本及既有文件完整性，不向失效 PDF 引用应用页码。

- 使用现有一次性原生 PostgreSQL、生产服务器及合成资料；未读取现有用户资料，未调用付费模型。PDF 页码映射测试使用显式保存的合成提取结构，未宣称跨浏览器原生 PDF 查看器兼容性已全部测试。
- 本机沿用官方 webpack 构建路径，未更改默认构建配置；先前记录的 Turbopack 子进程问题不在本任务修复范围内。全量单测顺序执行以控制 PGlite 内存占用。
- 手机/桌面截图存放在忽略目录 `artifacts/citation-reading/`；未提交数据库、原件、缓存、构建产物或临时截图。
- 原有五份未提交文档保留，未纳入本任务提交。
