# 当前版本演示顺序

版本 1.0.0-rc.2 / 7ed9043。先完成真实 preflight，确认设置页版本。

1. 首页点击“体验引用核对”。说明这是无需模型的预设交互，点引用立即看到出处。
2. 切到已准备好的真实问答，展示 Query / Key / Value 回答，点引用、查看高亮上下文、打开 PDF 原件。第一分钟内交代价值。
3. 进入专用演示工作区，上传推荐八份合成文件，启动整理。主要操作在顶部，展开一份资料审阅；应用方案。
4. 从保存结果进入“向这批资料提问”。需要时只用一个“准备搜索”入口。明确当前资料范围。
5. 展示图片引用和新旧审计政策的来源差异，不把模型结论当作自动裁决。
6. 简要展示图谱、人工确认与专用演示重置范围。结束回到来源核对。

真实测试是否通过以当天 receipt 为准。服务不可用时展示保存的资料和原件，明确说明状态，不用预设示例冒充在线回答。
