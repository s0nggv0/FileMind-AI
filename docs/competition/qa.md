# 答辩问答

**为什么先看引用？** 用户需要判断结论依据，当前首页示例和正式演示都提前展示原文核对。

**AI 能直接修改资料吗？** 先生成结构化建议，用户审阅后应用；模型只调用注册工具，执行仍受身份、版本与事务约束。

**怎样约束开发 AI？** 明确需求、文件范围和不变条件，先查看本地框架文档，分模块提交；用实际测试失败反馈引导修复。完整原始聊天是证明，代码 Prompt 不是替代品。

**成绩是否证明真实长文准确？** 不能。历史数据以原创合成语料为主，生成和判断共享模型家族；已发布答案的条件指标不等于所有问题准确率。

**十分钟是否保证？** 便携包减少安装工作；需要预先取得有效 Key、可用网络和受支持系统。下载和注册耗时单列，具体实测看 receipt。

**怎样确认同一版本？** 比较 current-release.json、设置页和 ZIP manifest 的应用提交；材料可由后续文档提交补充。

**还未完成什么？** 用户口播剪辑、三条原始完整 Prompt 链的最终核对、团队信息和官网提交。扫描 PDF、账号系统和大规模向量索引后置。
