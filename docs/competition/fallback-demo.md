# 在线演示与故障备用流程

正常演示使用在线 AI。2026-10-04 的验收通过了扁平 schema、Conflict、Ambiguity、主 Demo 全流程和 12/12 检查，Agent 没有 Planner 回退，详见 [验收记录](release-freeze.md)。Phase 9 最初六次失败调用另有记录。

云服务故障时，继续展示已保存、已索引资料的本地功能，并说明云端 AI 服务不可用。展示旧答案时注明生成时间。比赛模式不切换到模拟引擎。

| 故障 | 继续展示 | 说明 |
| --- | --- | --- |
| Kimi 超时或结构校验失败 | 资料库、关键词查找、来源与原文 | 本次答案未通过发布验证。 |
| DashScope 故障 | 关键词查找、原件 | 语义检索不可用。 |
| Vision 不可用、OCR 成功 | 原图、本地 OCR 和状态 | 仅提取文字，未理解图形。 |
| OCR 不可用、已有 Vision 结果 | 已有解释和原图 | 模型解释不能当作准确转录。 |
| 两图像路径失败 | 原图、无可索引内容 | 不制造图像知识。 |
| PostgreSQL 故障 | 错误信息、静态演示资料与报告 | 保存、应用和导入未成功。 |
| 原文件缺失 | 缺失提示、保留正文、存储维护 | 原文链接不可用。 |
| Agent 失败 | 实际诊断、此前保存 Workspace | fallback 不等于 LLM 计划成功。 |
| 索引中断 | 仍有效的已发布索引与重试 | 新资料不冒用旧索引。 |

备用演示依次打开资料库、按关键词查找 QKV、核对原文或原图、展示本地 OCR 和知识图谱、校验备份，最后说明身份恢复。隐藏真实密钥；备份 ZIP 没有加密。重置前确认专用身份并停止活动索引，取消操作会保留资料。

本地验收覆盖了新环境数据库、OCR、Recovery、Backup 完整性和五次 scoped reset。浏览器中的云故障测试使用注入响应，证明界面能处理指定错误；第三方实际故障和问答质量需分别验证。
