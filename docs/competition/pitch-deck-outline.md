# Competition Pitch Deck Outline

12 页答辩大纲。建议 6 分钟讲解，产品演示另按视频脚本执行。本交付为逐页内容和讲述要点，未生成 PPTX 成片。

| 页 | 标题 / 核心句 | 视觉证据 | 讲述要点 |
| --- | --- | --- | --- |
| 1 | Problem：记得知识，忘记文件 | 原创混合资料与一个具体 QKV 问题 | 文件名搜索难以贯穿格式和图像 |
| 2 | FileMind AI：Turn scattered files into connected knowledge. | Landing 截图 | 个人知识空间，用户掌握决策 |
| 3 | Core Experience：Import → Agent → Review → Ask → Citation | 单一主 Demo 的连续真实操作 | 展示工作路径，说明等待与错误 |
| 4 | Agent Architecture：限定工具中的可见执行 | Agent / Tool Registry / Human Review 流程 | 结构化规划、白名单、工具校验、有限重试 |
| 5 | RAG：回答能回到原文 | Search、PDF 引用抽屉 | 所有权、位置、版本、事实验证 |
| 6 | Multimodal：图片也能成为有来源的知识 | 原图、OCR、AI interpretation 并排 | 提取与解释分开，失败保持诚实 |
| 7 | Safety：AI proposes. You decide. | Review、冲突面板、澄清选项 | 注入防护、拒答、用户选择、备份校验 |
| 8 | Evaluation：排名、回答与失败分别评价 | Phase 6/7/8 表格，保留 5.88%、2/8、0/8 | 合成语料、同模型评委、条件分母，公开本次真实 schema 失败 |
| 9 | Innovation：四个可解释的设计 | 四项设计与实际证据 | Agent 组织、多模态索引、自适应检索、可引用且由人控制的 AI |
| 10 | Engineering：能保存、能恢复、能迁移 | Journal、Reset 五次、干净目录验收 | 原子发布、FORCE RLS、便携 Windows 运行时 |
| 11 | Value：个人资料的连续知识工作流 | 学生／研究者的使用场景 | 不宣称无限规模，不编造用户数量或商业收入 |
| 12 | Closing：当前交付与发布门槛 | v1.0.0-rc.1 候选和剩余门槛 | 真实在线验收、当天 12/12 preflight、成片和正式团队信息待完成 |

备用页不计入本 12 页：原始评测协议、慢查询与容量实验、完整安全测试、授权范围、失败回执。架构只放一页，不展示全部 class/API/table。展示截图时注明本地注入的状态测试，不能作为现场真实模型成功证据。
