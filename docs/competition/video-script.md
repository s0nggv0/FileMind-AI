# 比赛视频脚本：6 分 10 秒

唯一主 Demo 使用八份推荐资料。目标录制时长 6:10，产品操作约 3:00，技术和评价约 1:55，背景与结束约 1:15。下列时间包含真实处理等待；若网络慢，应剪辑等待并明确标注时间压缩，不能伪造即时处理。本文件是可录制脚本，**不是已完成视频**。当前候选真实在线彩排未通过验收，不应据此宣称全部场景已成功。

| 时间 | 镜头与操作 | 口播 |
| --- | --- | --- |
| 0:00–0:30 | 文件夹中的 PDF、课件、截图和笔记，进入 Landing | 电脑里的资料越来越多，但真正需要某条知识时，我们往往记得内容，却记不起文件名。同一个概念可能出现在课堂笔记、PDF 和一张白板照片里。找到文件只是开始，我们还需要知道它讲了什么，以及回答能否回到原始依据。 |
| 0:30–0:55 | 展示 FileMind AI 标题与主入口，打开专用 Workspace | FileMind AI 把散乱的个人资料变成可理解、可搜索、可关联的个人知识空间。这里的资料全部是我们原创的演示内容。整个过程有一个明确原则：AI proposes. You decide. |
| 0:55–1:15 | 拖入八份混合资料，启动 FileMind Agent | 这次一起导入 PDF、Word、Markdown、文本和两张图片。FileMind Agent 读取内容，提出分类、标签、命名和关联建议。页面上的工具活动反映实际执行状态，遇到错误会保留文件并提供重试。 |
| 1:15–2:00 | Reading / Understanding / Classifying / Tagging / Connecting 实际活动，保留合理等待 | 文档文字在本地解析。图片分别经过可见文字提取与视觉理解，OCR 原文和 AI 解释分开展示。Agent 通过限定工具工作，不能自行运行任意命令或删除文件。这里展示的是模型和工具执行结果，而不是预设的分析动画。 |
| 2:00–2:25 | Review，修改一个真实提案，Apply | 整理建议先进入 Review。我可以修改分类、删去不合适的标签，或者拒绝命名建议。只有确认 Apply 后，接受的方案才保存到我的知识空间。人工确认让使用者始终掌握资料的组织方式。 |
| 2:25–3:05 | Search 主 QKV 问题，打开 PDF 和图片引用 | 现在问：我的哪些资料讲过 Transformer 中的 Query、Key、Value？系统检索文字和图像中的相关证据，生成回答之前检查引用与事实支持。我可以点击引用，回到 PDF 或原图，检查这句话来自哪里。我们把引用当成核对入口，不把有引用等同于一定正确。 |
| 3:05–3:25 | Follow-up Retrieval；BERT 问题如实无依据，或预先验收后的 Self Attention 补问 | 接着问这些资料和 BERT 有什么关系。当前八份资料没有说明 BERT，合理结果是缺少依据。要展示有依据的追问，可以问这些资料怎样通过注意力权重组合 Value。两种结果都必须来自实际检索，不能用模型的外部常识补齐资料。 |
| 3:25–3:55 | Graph 关联，Cleanup 审阅真实候选，Settings Recovery / Backup | 知识图谱展示已保存资料的联系。Smart Cleanup 提供需要审阅的建议，文件不会直接被删除。Settings 中可生成恢复密钥，也能导出校验备份。备份默认没有加密，需要由用户妥善保存。 |
| 3:55–4:35 | 一页架构图与 Agent 流程 | 前端使用 Next.js、React 和 TypeScript。FileMind Agent 调用文档工具，Kimi 负责结构化分析和回答，Kimi Vision 与 Tesseract 处理图片，DashScope 提供独立 Embedding。知识层负责检索、引用和事实验证，PostgreSQL 与私有文件存储保留数据。 |
| 4:35–5:20 | Adaptive 实验图，安全与备用冲突／澄清画面 | 检索策略由评价推动。在 Phase 6，始终混合的排名低于纯向量，我们据此设计了 Adaptive Retrieval。另一个重点是问题边界：资料冲突时展示双方，实体不清楚时询问用户。Phase 9 的本地流程测试通过，但本次真实模型抽验遇到 schema 失败，尚不能宣称真实质量问题已经全部解决。 |
| 5:20–5:50 | 同时展示漂亮指标与弱项 | Phase 8 首次盲测有 90 份资料、180 个问题。检索指标达到满分，但回答仍有 5.88% 误拒答，完整冲突检测只有 2/8，歧义澄清为 0/8。引用和事实指标针对已经发布的答案，不能当成所有问题的成功率。我们保留首次结果，也保留本次失败抽验。 |
| 5:50–6:10 | 回到产品和真实交付状态 | FileMind 的价值是把文件组织、内容检索和依据核对连接起来。下一步发布必须先通过真实在线验收。网络不可用时，可以展示已保存资料、本地 OCR、关键词检索和备份恢复，并明确说明 Cloud AI provider unavailable。 |
