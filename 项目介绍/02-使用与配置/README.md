# 使用与启动

1. 打开旁边的 `项目` 文件夹，双击 `启动 FileMind.bat`，使用启动窗口显示的网址。
2. 需要停止时，双击同一目录的 `停止 FileMind.bat`。

完整既有使用说明保存在 [使用说明.md](使用说明.md)。配置与开发方法见 [程序 README](../../项目/README.md)、[模型与数据库配置](../../项目/docs/setup/postgresql-kimi.md)。

源码开发命令需要先进入 `项目` 目录：

```powershell
cd .\项目
npm run dev
```

已有本地运行环境随程序原样移动。
