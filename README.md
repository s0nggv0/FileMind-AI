# FileMind AI · 从这里开始

导入文档、笔记和图片，审阅整理建议，再提问并点击引用核对原文。

| 你要做什么 | 打开哪里 |
| --- | --- |
| 启动或开发程序 | [项目](项目/README.md)，双击其中的 `启动 FileMind.bat` |
| 了解项目、查看使用与技术说明 | [项目介绍导航](项目介绍/README.md) |

```text
AI_WEB/
├─ 项目/                     程序、运行环境、源码、开发测试及技术文档
├─ 项目介绍/
│  ├─ 01-项目介绍/            产品与设计说明
│  ├─ 02-使用与配置/          使用说明和启动导航
└─ README.md                 本导航
```

开发命令从程序目录运行：

```powershell
cd .\项目
npm run dev
```

`项目/tests/` 保存开发者的自动化测试。

环境配置、用户数据和运行缓存仍留在 `项目/` 的私有目录中，不属于可分享的介绍或测试资料。Git 提交规则见 [AGENTS.md](AGENTS.md)。
